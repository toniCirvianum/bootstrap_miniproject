# Bootstrap - Mini projecte

Aquest mini projecte conté els 4 exercicis resolts del document "Exercises UF1 - Bootstrap".

## Fitxers

- `index.html` - menú principal
- `exercise1.html` - perfil d'usuari responsive
- `exercise2.html` - formularis Bootstrap
- `exercise3.html` - administració de productes amb taula responsive
- `exercise4.html` - catàleg responsive amb cards
- `assets/` - imatges de mostra

## Característiques

- Només s'utilitza Bootstrap per als estils.
- No hi ha CSS personalitzat.
- Els comentaris dins del codi estan en català.
- Les solucions són intencionadament simples i pensades per a alumnes que comencen amb Bootstrap.
